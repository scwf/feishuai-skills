# 研究提取摘要 (Research Extraction Summary)
* **大模型预训练能力 (Pre-training)**
  * **集群规模**：支持单集群 10 万卡规模，万卡规模下 GPU 线性扩展效率大于 96%。
  * **网络架构**：升级至 HPN 8.0，支持 $10\times10$ 万卡连接规模，片间/节点间网络带宽达 800Gbps。
  * **框架加速**：基于 PAI 平台，Qwen3.5 MOE 训练加速提升 3 倍；自研预训练框架 TrunkFlow 和 Microtrunk 端到端性能提升 4-5 倍；具备 Checkpoint HA 高可用能力，应对硬件故障。
  * **磐久 AL128 超节点**：搭载自研 ICN Switch 1.0 互联芯片，将 128 张真武 M890 AI 芯片连接成单一算力资源池（9.2TB 超级内存池），芯片间 P2P 时延 <150ns，片间带宽 800GB/s，单节点内即可完成超大模型分步训练。
* **大模型后训练能力 (Post-training)**
  * **Agentic 强化学习**：全面向 RLVR（Reinforcement Learning with Verifiable Reward）范式演进，优化自主执行、多步规划和工具调用。
  * **沙箱评测规模**：单任务支持扩展至万级沙箱（10,000+ Sandbox）并发运行和评测 Agent 任务。
  * **百炼平台调优**：提供一站式闭环调优（API化操作，屏蔽GPU管理）；开箱即用支持 GRPO 和 DPO 强化学习算法；白盒化训练面板支持轨迹分析、奖励分配分析和工具调用监控。
* **推理服务能力 (Inference Serving)**
  * **极速弹性与调度**：
    * **Flashboot 引擎**：优化权重文件加载，Qwen3.7-Max 启动与加载时间由 1200 秒压缩至 90 秒。
    * **Unischeduler 调度器**：集群调度决策时间从 20 秒降至 0.4 秒，弹性响应时间降低 81%，可在 1 分钟内拉起 1 万个 Pod。
  * **单次推理性能 (TTFT / TPOT)**：
    * Qwen3.6-Plus 在 PTO（预置吞吐单元）推理下，TTFT（首包延迟）下降 38%；TPOT（Token 输出延迟）从 25 毫秒优化至 10 毫秒（输出速度 100+ Tokens/s）。
    * 引入多阶段 QoS 和 SO 调度，峰值异常频率降低 98%，峰值请求吞吐提升 2 倍。
  * **TEL 全局分布式 KV 缓存与降价**：
    * 自研分布式全局 KV 缓存框架，使 Attention 内存缓存命中率达 90% 以上。
    * 长对话场景下，重复上下文计算成本降低 97%~98%，多轮对答首包延迟降低 85%。
    * 商业定价中，Problem Caching（Prompt 缓存）价格降低 90% 以上。
  * **批量推理 API & 售卖形态**：
    * 推出 Batch Chat 接口，兼容标准 Completion 协议，支持异步批量处理。
    * 提供预置吞吐单元（PTO）和模型单元（MU）等资源预留模式，支持百万级上下文和千万级 TPM 默认突发。

# 核心判断 (Core Judgment)
阿里云通过底层磐久超节点与 HPN 8.0 网络、后训练 Agentic RLVR 以及推理 TEL 全局 KV 缓存的全链路技术升级，打造了低时延、万级高弹性、极致性价比的 Agentic 时代大模型算力与推理底座。
