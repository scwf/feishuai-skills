# 阿里云千问云战略与能力全景图 - 信息图提示词生成

## 1. Research Extraction Summary (研究提取摘要)
*   **组织架构重构（ATH 事业群）**：
    *   **ATH 定义**：Alibaba Token Hub，由阿里集团 CEO 吴泳铭亲自挂帅，于 2026 年成立。核心逻辑是围绕 Token 的生产、输送和应用，组织基本单位由“产品/流量”切换为“Token”。
    *   **三段式分工**：
        *   **创造 Token**：通义实验室负责，主攻底层大模型（Qwen）研发。
        *   **输送 Token**：MaaS（模型即服务）业务线负责，其底座为百炼平台。
        *   **应用 Token**：千问事业部、悟空事业部、AI 创新事业部负责，推动 Token 落地 C 端与 B 端具体应用。
*   **平台底座与入口关系**：
    *   **百炼平台**：归属于千问云，扮演后端技术与推理引擎角色（负责 Token 的调度、微调、安全、加速等硬核技术层）。
    *   **千问云官网 (www.qianwenai.com)**：前端统一 AI 服务入口和 AI 时代独立门户，首个独立于阿里云传统官网（aliyun.com）的全新官网。
*   **千问云两大核心定义**：
    *   **“为 Agent 而生的新入口”**：AI-First，摒弃传统云复杂的控制台和产品树，实现 Agent 友好。
    *   **MaaS 开放大集市**：面向全球开发者提供统一的模型 API 集成界面，售卖自研及全球第三方大模型。
*   **千问云四大核心功能发布**：
    1.  **150+ 主流模型 API 一站式接入**：通过统一 API 接口访问通义千问系列（Qwen3.7-Max、Qwen-Omni 多模态模型、语音/同传等）、第三方生态模型（智谱 GLM-5.1、MiniMax M2.7、月之暗面 Kimi K2.6、快手可灵 Kling、生数科技 Vidu Q3等）及其他开源/闭源模型（DeepSeek、Wan、HappyHorse等）。
    2.  **模型核心能力 Skills 化与 CLI 化**：封装模型核心功能。Skills 化将能力转化为 Agent 可调用的标准技能模块；CLI 提供命令行工具让 Agent 在隔离沙箱内自主操作和管理模型。
    3.  **Agent 自主用量管理**：Agent 在运行期间实时调用用量接口获取自身 Token 消耗，并能自主分析用量趋势，识别死循环或幻觉导致的 Token 异常暴涨，执行中断、回滚或优化。
    4.  **人类开发者的极简体验**：提供大模型 Playground。支持在同一界面输入相同 Prompt，同步对比多款模型（如 Qwen3.7 对比 GLM-5.1、Kimi K2.6）的输出质量，提供快速选型评测工具。

## 2. Core Judgment (核心判断)
千问云作为阿里云首个AI原生的独立入口，标志着阿里在组织维度完成了围绕Token生产、输送与应用的“ATH事业群”战略闭环，在产品维度通过百炼平台底座与Agent/CLI友好接口，实现了从“以传统云资源为中心”到“以Token和Agent为中心”的历史性跨越。
