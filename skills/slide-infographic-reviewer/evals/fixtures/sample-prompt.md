# Infographic generation prompt

Create a horizontal 16:9 executive infographic about an AI platform strategy.

Core judgment: The platform wins by coordinating infrastructure, models, and applications rather than relying on one model.

Layout:

- Top: judgment-style title.
- Left two-thirds: three-layer architecture with Infrastructure -> Model Platform -> Applications.
- Right one-third: three insight cards mapped one-to-one to the layers.
- Bottom: concise conclusion.

Use a restrained red, black, white, and gray palette. Show relationship arrows between layers. Keep all visible Chinese copy concise and avoid decorative 3D effects.
